# 论文订单管理系统

一个可直接在浏览器打开的教务端原型，覆盖期刊论文订单录入、客户资料登记、老师审核、投稿跟进、返修、录用、校稿、online 与检索提醒。

## 使用方式

1. 直接双击打开 `index.html`。
2. 使用以下演示账号登录：
   - 教务：`academic / academic123`

## 当前功能

- 教务可录入客户基本信息、个人信息登记表状态、老师信息、审核节点、投稿账号和投稿网址
- 支持新老师创新点审核、稳定老师跳过创新点、初稿审核、编辑审查、投稿前作者信息核对
- 支持投稿后一周查稿、每周查稿、Under Review 提醒、返修提醒、版面费提醒、校稿、online、检索和审查报告提醒
- 支持按附件类型上传登记表、投稿截图、录用截图、online 截图和检索截图，数据保存在浏览器 `localStorage`
- 支持关键词搜索和按论文进度筛选

## 说明

- 这是一个前端原型，数据存储在当前浏览器本地；清理浏览器缓存后数据会消失
- 如果你后续需要，我可以继续把它升级成带数据库和正式登录权限的完整系统
