# v1.3 测试用例文档 - 主管端

> **版本**：v1.3  
> **适用端**：主管端 `admin / owner`  
> **依据文档**：`doc/v1.3-四端口迭代任务清单.md`（OP-20、OP-21、SUP-1 ~ SUP-3）  
> **覆盖范围**：主管作品看板指标清理（OP-20）、主管作品看板时间筛选+排序（OP-21）、主管手动标记优秀作品（SUP-1）、主管端个人看板同步运营端（SUP-2）、主管端接收跨端口提醒（SUP-3）。  
> **跨端提示**：SUP-1 与运营端 OP-10 学习榜单「主管推荐」联动；SUP-2 与运营端 OP-1/2/3/16-19/23/24 看板数据口径一致；SUP-3 与销售端 SA-4、运营端 OP-13 三角色提醒互通。

---

## 一、测试目标

1. 主管作品看板完成「减法」：删除「作品总数 / 获客贴数(≥5) / 待补充建议(≥3 客资)」三张顶部阈值卡，改为列表内联标记。
2. 主管作品看板新增交互能力：顶部时间筛选器（今日 / 本周 / 本月 / 累计 / 自定义）与列排序（日期 / 流量 / 获客 升/降序），默认按发布日期倒序，分页保留 20/50 条。
3. 主管可在作品看板行内对单条作品标记/取消标记「优秀作品」，运营端学习榜单「主管推荐」板块实时同步，仅主管自己可见自己的标记记录。
4. 主管端个人看板（员工选择器）同步运营端 OP-1/2/3/16-19/23/24 全部能力：指标维度/平台/时间三维切换、名次展示、顶部 5 张概览卡、三大效率榜、双平台饼图+柱状图、账号分析子菜单、legacy 样式效率榜。切换员工后所有卡片/榜单/图表严格对应选中员工数据。
5. 主管可在消息中心、客资看板、订单看板中接收销售/运营发来的跨端口提醒，支持回复和转发到其他角色。
6. 主管端所有变更不破坏既有统计口径（流量 = likes+comments+favorites，不含分享）与权限边界（admin/owner 区分、运营端数据隔离不受影响）。

## 八、主管端验收通过标准

1. **P0 用例全部通过**。

3. 主管作品看板顶部三张阈值卡彻底删除，列表内联标记代替阈值提示。
