## 三、完成项

### A-FE-4 运营作品录入

- 提交成功后跳转到当日本地日期的作品列表筛选页。
- 作品列表展示“今日录入记录”提示。
- E2E 覆盖 `POST /api/posts` 和跳转到今日记录。
- E2E 覆盖上传失败后文本字段不丢失。

### A-FE-5 运营客资录入

- 本地草稿保存、刷新恢复、提交成功后清理草稿。
- 支持来源账号、来源作品、销售下拉、引流截图。
- E2E 覆盖草稿恢复、提交客资、分配销售。

### A-FE-6 运营客资看板

- 使用 `ProTable` 展示运营客资。
- 支持分页、平台筛选、状态筛选、搜索和排序。
- 展示来源账号、来源作品、分配销售、添加状态、协同状态、客资状态、最后更新时间。
- 后端映射补充账号/作品名称，前端统一使用 `StatusTag`。

### A-FE-7 运营协同处理

- 展示客户信息、来源作品、销售备注、协同原因。
- 支持处理类型：已提醒客户、已补充信息、已二次触达。
- 加载待处理任务后自动选中第一条可处理任务，避免看到详情但无法提交。
- 提交后调用协同处理接口，并由后端通知销售端。

### A-FE-8 运营消息入口

- 运营消息列表支持协同申请展示、查看并已读。
- 后端通知跳转修正为新前端存在的路由：
  - lead：`/operation/leads?leadId=...`
  - collaboration task：`/operation/collaboration?taskId=...`
- E2E 覆盖运营消息点击跳转到协同处理页。

```text
运营真实登录
-> 录入作品

-> 销售收到处理结果通知
-> 运营看板看到销售状态回写
```
