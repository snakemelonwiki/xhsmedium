## 修复项

1. 测试库 `users` 表缺少登录锁定字段，导致登录报 `Unknown column 'User.failed_login_count'`。
   - 已补：`failed_login_count`、`last_failed_at`
   - 日志：`doc/test-runs/live-playwright-20260602-210552-login-lockout-migration.log`

2. 测试库 `leads` 表与当前实体不一致，导致 `POST /api/leads` 和客资列表 500。
   - 已补：`requirement_note`、`supervisor_note`
   - 已将 `status`、`process_status`、`add_status` 对齐为当前 `schema.sql` 的 `VARCHAR(32)` 英文状态码
   - 日志：`doc/test-runs/live-playwright-20260602-210552-leads-schema-migration.log`

3. 协同任务 inbox 列表 500。
   - 根因：`collaboration_tasks.lead_id` 与 `leads.id` collation 不一致，join 时 MySQL 报 `Illegal mix of collations`
   - 修复：`backend/src/modules/collaboration-tasks/collaboration-tasks.service.ts` 的 leads join 显式使用 `COLLATE utf8mb4_unicode_ci`
   - 覆盖：`backend/src/modules/collaboration-tasks/collaboration-tasks.service.spec.ts`

4. 运营端作品录入 live 用例适配当前页面。
   - 账号字段已是 AntD Select，用例改为选择下拉选项
   - 接口失败断言补充状态码和响应体
   - 链接解析改为验证表单实际回填，不依赖短暂 toast

5. 主管端 live 用例适配当前功能。
   - 总览指标文案按当前页面调整
   - 导出/详情/改派/提醒从“缺失项”更新为“已存在功能”的验证
   - 导出任务状态兼容中文展示，如“已完成”

6. 跨端导出权限用例适配当前后端契约。
   - 当前后端允许运营导出 `accounts`，但强制将 `scope=all` 降级为 `mine`
   - 用例改为验证降级后的任务 filter，避免误判为应返回 403
