## 四、核心业务流程

### 4.1 认证与登录流程

```
用户                    前端(app.js)              后端(server.js)           数据层
 │                        │                          │                      │
 │  访问 http://:3000     │                          │                      │
 │───────────────────────→│                          │                      │
 │                        │                          │                      │
 │  输入用户名+密码        │                          │                      │
 │───────────────────────→│                          │                      │
 │                        │  POST /api/auth/login    │                      │
 │                        │  {username, password}    │                      │
 │                        │─────────────────────────→│                      │
 │                        │                          │  查询 users 表       │
 │                        │                          │─────────────────────→│
 │                        │                          │  ← {user, role}      │
 │                        │                          │←─────────────────────│
 │                        │                          │                      │
 │                        │                          │  端口角色校验:        │
 │                        │                          │  3000: 非owner       │
 │                        │                          │  3001: 仅owner       │
 │                        │                          │                      │
 │                        │                          │  生成 UUID Token     │
 │                        │                          │  存入 sessions Map   │
 │                        │                          │                      │
 │                        │  ← {token, user}         │                      │
 │                        │←─────────────────────────│                      │
 │                        │                          │                      │
 │                        │  保存 token 到           │                      │
 │                        │  localStorage            │                      │
 │                        │                          │                      │
 │                        │  根据 role 渲染          │                      │
 │                        │  对应端口导航            │                      │
 │                        │                          │                      │
 │  看到对应端口界面      │                          │                      │
 │←───────────────────────│                          │                      │
 │                        │                          │                      │
 │  后续请求              │                          │                      │
 │───────────────────────→│  Authorization:          │                      │
 │                        │  Bearer <token>          │                      │
 │                        │─────────────────────────→│                      │
 │                        │                          │  authRequired 中间件 │
 │                        │                          │  验证 token          │
 │                        │                          │  附加 req.session    │
 │                        │                          │                      │
 │                        │                          │  处理业务逻辑        │
 │                        │  ← 响应数据              │                      │
 │                        │←─────────────────────────│                      │
 │  看到数据/操作结果     │                          │                      │
 │←───────────────────────│                          │                      │
```

### 4.5 排行榜与看板数据流

```
┌─────────────────────────────────────────────────────────────────────────┐
│                          数据聚合流程                                    │
│                                                                         │
│  posts 表 ──┬──→ COUNT(posts) ──→ 作品数榜单                            │
```

```
│  │       → 只允许 role === "owner"                            │  │
│  │     req.socket?.localPort === 3000                         │  │
│  │       → 拒绝 role === "owner"                              │  │

│  │  admin  → 返回 null (看全部)                               │  │
│  │  owner  → 返回 null (看全部)                               │  │
```
