## 2. 订单状态机与状态流转图

### 2.1 订单主状态机（order_status）

```mermaid
stateDiagram-v2
    [*] --> pending_accept: 订单创建（销售成交）
    pending_accept --> in_progress: 教务接收订单
    in_progress --> waiting_material: 教务更新状态
    waiting_material --> waiting_teacher: 教务更新状态
    waiting_teacher --> delivering: 教务更新状态
    delivering --> completed: 教务确认交付
    delivering --> abnormal: 提交异常反馈
    in_progress --> abnormal: 提交异常反馈
    waiting_material --> abnormal: 提交异常反馈
    waiting_teacher --> abnormal: 提交异常反馈
    abnormal --> in_progress: 异常关闭（回退）
    abnormal --> completed: 异常处理完成后确认交付
    completed --> [*]
    delivering --> closed: 订单关闭
    in_progress --> closed: 订单关闭
    waiting_material --> closed: 订单关闭
    waiting_teacher --> closed: 订单关闭
    closed --> [*]
```

**状态枚举值对照表**：

| code（文档） | DB 实际值 | 中文 |
| --- | --- | --- |
| `pending_accept` | `to_receive` | 待接收 |
| `in_progress` | `in_progress` | 进行中 |
| `waiting_material` | `awaiting_client_info` | 待客户资料 |
| `waiting_teacher` | `awaiting_teacher` | 待老师安排 |
| `delivering` | `to_deliver` | 待交付 |
| `completed` | `completed` | 已完成 |
| `abnormal` | `abnormal` | 异常 |
| `closed` | `closed` | 已关闭 |

### 2.2 付款状态机（paid_status）

```mermaid
stateDiagram-v2
    [*] --> unpaid: 订单创建
    unpaid --> partial_paid: 部分付款
    partial_paid --> paid: 全额付款
    partial_paid --> refunded: 退款
    paid --> refunded: 退款
    paid --> [*]
    refunded --> [*]
```

**状态枚举值**：

| code | 中文 |
| --- | --- |
| `unpaid` | 未付款 |
| `partial_paid` 或 `partial` | 部分付款 |
| `paid` | 已付款 |
| `refunded` | 已退款 |

### 2.3 交接状态机（handover_status）

```mermaid
stateDiagram-v2
    [*] --> pending: 早期版本
    pending --> handed_over: 销售手动交接
    handed_over --> accepted: 教务接收
    handed_over --> rejected: 教务拒收
    rejected --> pending: 重新交接
    accepted --> [*]
    rejected --> [*]
    
    [*] --> handed_over: 销售成交（当前版本直接落 handed_over）
```

**4 个 Handover 路由**：

| 路由 | HTTP 方法 | 触发动作 | 状态变更 |
| --- | --- | --- | --- |
| `hand-over` | POST | 销售手动发起交接 | `pending → handed_over` |
| `accept` | POST | 教务接收订单 | `handed_over → accepted` + `order_status: to_receive → in_progress` |
| `reject` | POST | 教务拒收订单 | `handed_over → rejected`（必须传 reason） |

### 2.4 异常反馈状态机

```mermaid
stateDiagram-v2
    [*] --> open: 创建异常反馈
    open --> handling: 开始处理
    handling --> closed: 处理完成
    open --> closed: 直接关闭
    closed --> [*]
```
