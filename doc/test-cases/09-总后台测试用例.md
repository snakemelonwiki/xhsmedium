## 一、文档概述

### 1.1 测试范围

总后台（3001）面向业主（owner 角色），目标是做成"老板驾驶舱"，而不是主管端镜像。本文档覆盖：

1. **登录与跨端口越权**：3000/3001 双端口登录语境、跨端口拦截
2. **导航与菜单权限**：总后台只含总览/作品监控/客资监控，不含员工/账号/分析/导出
3. **老板判断卡**：管理覆盖 / 运营沉淀 / 销售推进
4. **看台分层**：主管总看台 / 销售总看台 / 运营总看台
5. **作品/客资监控**：总后台版（含引流截图无脱敏）
6. **数据口径差异**：owner 与 supervisor 6 项核心指标差异
7. **WebSocket 独立命名空间**与导出权限差异
8. **真实缺陷回归**：PF-05（失效 token）、PF-06（跨端口越权）

### 1.2 角色与端口对照

| 角色 code | 允许登录端口 | 备注 |
| --- | --- | --- |
| `operation` | 3000 | 运营员工，禁止登录 3001 |
| `sales` | 3000 | 销售，禁止登录 3001 |
| `academic` | 3000 | 教务，禁止登录 3001 |
| `supervisor` | 3000 | 主管，禁止登录 3001 |
| `admin` | 3000 | 主管端高级权限，禁止登录 3001 |
| `owner` | 3001 | 业主/总后台，**禁止登录 3000** |

### 1.3 前置条件

- 后端服务运行中，端口 3000/3001 双实例
- MySQL 数据库已启动，`users.role='owner'` 测试账号已创建
- 浏览器可访问 `http://localhost:3001`
- 测试账号：owner_test1（owner 角色）；supervisor_test1（supervisor 角色）
