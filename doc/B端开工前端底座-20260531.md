# B 端开工前端底座优先级 - 2026-05-31

> 依据：`doc/v1.1-运营到销售核心协同版-AB端任务分配-前端重构版.md`

## 结论

要让 B 端销售侧可以开始工作，不需要等旧前端全量迁移完成。必须先交付的是 **M0 前端底座 + 销售端最小路由 + 统一业务契约**：

```text
frontend/ 可启动
-> 能登录并识别角色
-> 能进入 /sales/*
-> B 能复用 apiClient、状态枚举、StatusTag、LeadCard、LeadTimeline、NotificationBell
-> B 可以独立开发“我的客资 / 详情 / 跟进 / 协同 / 消息”
```

## P0 必须先完成

| 优先级 | 底座项 | 交付物 | 解锁 B 端能力 |
| --- | --- | --- | --- |
| P0-1 | Next.js 工程壳 | `frontend/`、3302 端口、构建/测试脚本 | B 可以在新工程写页面，不再改旧 `public/js/leads-monitor.js` |
| P0-2 | 登录与权限壳 | `/login`、角色默认首页、未登录/无权限处理 | B 可以验证销售入口和销售菜单 |
| P0-3 | 销售端路由 | `/sales/leads`、`/sales/leads/[id]`、`/sales/followups`、`/sales/collaboration`、`/sales/messages` | B 可以按页面并行开发 |
| P0-4 | 统一 API Client | token、401、分页、错误、FormData、Abort signal | B 不需要每页重写请求层 |
| P0-5 | 状态与类型契约 | lead/add/process/collaboration/notification 枚举和 TS 类型 | B 的状态机、筛选、标签不会字段发散 |
| P0-6 | 销售共享组件 | `StatusTag`、`LeadCard`、`LeadTimeline`、`NotificationBell`、`ConfirmActionButton` | B 可以先搭页面，再逐步接真实接口 |

## B 端第一批可并行页面

第一批只追求“销售能开始工作”的最小链路。

| 页面 | 路由 | 先做能力 | 可延后 |
| --- | --- | --- | --- |
| 我的客资 | `/sales/leads` | 分页列表、状态筛选、客资卡片、详情跳转 | 复杂多维筛选、批量操作 |
| 客资详情 | `/sales/leads/[id]` | 基础信息、来源、状态、跟进时间线、协同时间线 | 完整订单联动 |
| 待跟进 | `/sales/followups` | 可先复用列表筛选和快速跟进 | 独立复杂工作台 |
| 协同 | `/sales/collaboration` | 从卡片/详情发起协同，列表可先占位 | 协同统计 |
| 消息 | `/sales/messages` | 未读列表、routeHint 跳转、标记已读 | WebSocket 实时推送 |

## 接口契约优先顺序

1. `GET /api/leads?limit=20&offset=0&scope=self`
   - 销售只看分配给自己的客资。
   - 前端统一转换为 `{ items, total, page, pageSize }`。

2. `GET /api/leads/:id`
   - 销售详情页使用。
   - 如果后端暂缺专门详情接口，可先用列表项模型和后续接口补齐。

3. `POST /api/leads/:id/follow-records` 与 `GET /api/leads/:id/follow-records`
   - 销售开始记录跟进。

4. 状态更新接口
   - 文档目标是 `PATCH /api/leads/:id/status`。
   - 若后端暂未提供，可短期适配现有 `PUT /api/leads/:id/board`，但新前端接口层必须保留目标方法名。

5. 协同与通知接口
   - 目标为 `POST /api/leads/:id/collaboration`、`GET /api/collaboration-tasks`、通知列表/未读数/已读接口。
   - 若后端路径暂为 `POST /api/collaboration-tasks`，在 `apiClient` 业务封装层做适配，不让页面感知差异。

## M0 验收口径

- `frontend/` 能安装、启动、测试、构建。
- `/login`、`/sales/leads`、`/sales/leads/[id]` 路由存在。
- 销售菜单包含“我的客资、待跟进、协同、消息”。
- `apiClient` 能统一处理 token、分页、401、请求取消。
- 状态标签来自统一枚举，不在页面内散落中文状态。
- B 可以在不改旧 `public/js/*.js` 的情况下继续开发销售页面。
