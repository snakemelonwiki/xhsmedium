## 三、M5 回归发现与修复

### P1：`import_tasks` 实体与真实 DDL 不一致（已修）

**问题**：`backend/src/entities/import-task.entity.ts` 原本声明了 `status`（`@Column({ length: 32, default: 'processing' })`）和 `finished_at`（`@Column({ name: 'finished_at', type: 'datetime', nullable: true })`），并加了 `@Index('idx_import_status', ['status'])`。但权威 DDL（`ddl/06_v1_post_metrics_history_favorites_import_tasks.sql:49-66`）与 `schema.sql` 的两份 `import_tasks` 定义都没有这两列；同时实体里 `createdAt` 列名 `created_at` 也与 DDL 的 `create_time` 不符。

**影响**：

- #7 粘贴导入 `persistTask` 写库时会带 `status='completed'` + `finishedAt=Date`，新库（按 `ddl/06` 建表）会 `Unknown column 'status'`，整个导入抛错。
- 老库可能保留遗留 `created_at` 列因此暂时未爆，但代码与 DDL 不一致已是 P1 级偏移。

**修复**（已落到 dev 分支）：

- `backend/src/entities/import-task.entity.ts`：删除 `status` / `finishedAt` 字段与 `idx_import_status` 索引；`createdAt` 列名改为 `create_time` 与 DDL 对齐。
- `backend/src/modules/imports/imports.service.ts`：`createTask` / `finishTask` / `mapTask` 不再写读 `status` / `finishedAt`；`importLeadsPaste` 调用 `finishTask` 不再传 `status`。
- `backend/src/modules/imports/posts-bulk-import.service.ts`：`persistTask` 不再写 `status` / `finishedAt`；`listTasksForUser` 不再返回它们。

**复测**：`npx tsc --noEmit -p tsconfig.json` exit 0。

### 待跟进风险（非 A 端 6 项范围内）

### #6 作品广场权限与筛选

- `PUT /api/posts/:id`、`DELETE /api/posts/:id` 增加 staff 归属校验，员工只能修改 / 删除本人作品。
- 作品广场卡片补充展示收藏数、转发数、主管端总收藏次数。
- 作品广场补充账号筛选、最低获客数、最低点赞数、排序选择（综合 / 获客数 / 点赞数 / 发布时间）。

### #7 批量导入

- 作品与客资均支持粘贴导入、Excel/CSV 文件上传导入与模板下载。
- 失败行生成 `/uploads/import-errors/*-errors.csv`，接口返回并落库 `errorFileUrl`。
- 导入记录支持 admin / owner 使用 `scope=all` 查询全员记录。
- 客资录入页新增“批量导入客资”入口。

### #8 手动刷新指标

- 指标刷新链路补充 `shares` 字段；无法稳定抓取时回传 `0`，并避免无值覆盖已有转发数。
- 批量刷新支持当前筛选作品 ID 集合，失败结果返回作品标题与失败原因。
- 前端新增批量刷新失败明细面板，可重试失败项。

### #9 学习榜单与收藏

- 后端作品查询返回 `favoriteCount`，主管端可见总收藏次数。
- “我的收藏”支持按平台、类型、员工、账号过滤。
- 学习 / 排行榜补充获客效率、点赞数、非获客贴数维度。

### #10 性能与会话稳定性

- `/api/posts`、`/api/leads` 支持 `page/pageSize` 与 `limit/offset`，默认每页 20 条；前端列表分页切换时重新拉取。
- 图片增加懒加载；作品 / 客资提交增加防重复锁。
- 新增 `POST /api/auth/refresh`，前端按 JWT 过期时间自动续期；401 时先保存草稿并提示重新登录，不清空表单。
- 新增 `/notifications` Socket.IO Gateway 与前端通知通道，支持自动重连、心跳与局部状态更新，断线不触发表单重渲染。

### #11 图片与表单解耦

- 作品封面保持独立 uploader，提交时再 append 到 `FormData`。
- 客资截图改为局部重渲染上传区，不再因选择 / 重选图片触发整页重渲染。
- 上传失败只提示图片错误，文本字段与草稿保留。
