# v1.3 四端口迭代任务清单

> 来源：远程交流记录（v1.3 沟通要点）
> 原则：不区分 A/B 端，按四个端口维度组织；同一变更跨多端时在涉及端分别登记。
> 每条任务包含：编号、标题、来源描述、涉及页面/功能、涉及端口、优先级。

| 项目 | 说明 |
| --- | --- |
| 文档用途 | 作为 v1.3 迭代的需求拆解、页面修改、接口开发、测试验收的统一依据 |
| 设计原则 | 沿用 v1.2 已落地的权限、状态机、消息体系，按本次远程交流要点做增量 |
| 范围 | 仅列本次远程交流明确提出的变更；未提出但已规划的能力不纳入 |

## 任务优先级图例

- **P0**：阻塞核心业务，必须本版本完成
- **P1**：体验与效率优化，建议本版本完成
- **P2**：增强能力，可在后续小版本完成
